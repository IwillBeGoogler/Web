# Security policy

Report vulnerabilities privately. Do not open a public issue or pull request for them.

- Use GitHub's **Report a vulnerability** button (Security tab, "Private vulnerability reporting"), or
- email **security@iwillbegoogler.uz**.

Include what you found, how to reproduce it, and the affected version or commit. We acknowledge a report within 3 working days,
aim to fix confirmed issues within 90 days, and credit reporters who want it.

## Scope

In scope: this repository's code and the production site it deploys (iwillbegoogler.uz).
Out of scope: denial of service, volumetric or automated scanning that degrades the site, social engineering, spam,
physical attacks and third-party services.

## Rules for testing

Test only against your own accounts and data. Stop and report as soon as you reach another user's data, and do not keep,
copy or share it. Testing outside these rules is not authorised.

## Supported versions

Only the current `main` branch and the version running in production receive fixes.
