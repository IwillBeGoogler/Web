# Code of conduct

We want contributing here to be respectful and useful for everyone.

## Expected

- Be courteous and professional. Criticise code and ideas, not people.
- Assume good faith; ask before you conclude.
- Keep discussion on topic and in the open (issues and pull requests).

## Not acceptable

- Harassment, insults, threats, doxxing or discrimination of any kind.
- Sexual language or imagery, and unwelcome attention.
- Spam, advertising, and posting other people's private information or secrets.

## Enforcement

Maintainers may edit or remove comments, close issues and pull requests, and block people who break these rules, without notice.
Report a problem to **conduct@iwillbegoogler.uz** (or privately to a maintainer). Reports are handled confidentially.

This code applies in this repository and in any space where you represent it.
